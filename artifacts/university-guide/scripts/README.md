# Проверка источников оценок

Из корня проекта:

```sh
pnpm --filter @workspace/university-guide check:sources
```

Команда читает `qsSource` и `reviewSource` из `src/university-insights.ts`.
Общие ссылки проверяются один раз, но в отчёте перечислены все вузы и метрики,
использующие ссылку. Оценки, даты проверки и ссылки не изменяются.

Проверка запускается только вручную: `test`, `build` и сервер не обращаются
к внешним источникам. Обычные тесты самого проверяющего используют подставные ответы
и не зависят от сети.

По умолчанию выполняется один GET-запрос одновременно, между запросами
(включая перенаправления) — пауза 750 мс. Тайм-аут запроса — 10 секунд,
максимум 5 переходов на ссылку, автоматических повторов нет. Тело ответа
не скачивается целиком. Можно задать параметры:

```sh
pnpm --filter @workspace/university-guide check:sources --interval-ms 1500 --timeout-ms 5000 --max-redirects 3
```

Интервал и тайм-аут: целые числа от 100 до 60000 мс; переходы: от 0 до 10.
`--help` показывает справку без сетевых запросов.

Отчёт печатается по мере проверки: исходный URL, вуз, метрика, название
источника, HTTP-коды, каждый переход и причина ошибки (включая тайм-ауты,
DNS/TLS и циклы). В конце — число доступных ссылок, успешных перенаправлений
и ошибок. Код завершения: `0` — все доступны, включая успешные перенаправления;
`1` — есть ошибки доступности; `2` — неверные параметры или ошибка запуска.
Для сохранения отчёта можно перенаправить вывод в файл вне исходного кода.

HTTP 403 может означать защиту от ботов, 429 — ограничение запросов;
сетевой сбой не доказывает, что страница удалена. Доступность HTTP не подтверждает
содержимое страницы, принадлежность вузу или актуальность оценки. Ошибки и
перенаправления нужно проверить вручную в браузере; автоматически заменять
или удалять оценки по этому отчёту нельзя.
