---
name: Personal applicant tools
description: Product decisions behind university comparison, programme filters and personal admissions preparation.
---

The user chose a separate admissions preparation tab instead of the proposed budget calculator: add universities, see available admission information and mark what is ready. A profile should retain saved universities and personal progress. They requested simple username and password registration.

**Why:** These were the user's explicit choices when accepting the applicant-tools improvements.

**How to apply:** Treat checklist completion as the applicant's personal preparation, not a statement that a university has accepted their documents. Distinguish generic editable tasks from verified university or programme requirements.

Academic filters should use individually sourced programmes, not infer available subjects from a university's name or general reputation. Partial coverage is acceptable when the interface makes that limitation explicit.

**Why:** A guessed programme could incorrectly include or exclude a university in an applicant's search.

**How to apply:** Expand programme coverage from official sources. A university with no recorded programme has unknown coverage, not proof that it lacks the subject.
